# Branches

**Use `main` only.**

The branches `frontier/modernize-2026` and `frontier/2026-modernization` are old snapshots. Everything useful from them is already on main.

You can delete those two branches in GitHub:

1. Open the repo → Branches
2. Delete `frontier/modernize-2026`
3. Delete `frontier/2026-modernization`

After that, only `main` remains.
