## Execution Interfaces

**Micro**
- Input → single prompt / factory
- Output → complete funnel, course, landing + sequence
- Proof → turnkey file or live URL

**Operational**
- Input → multi-turn stateful request
- Output → department-grade workflow (support desk, brand voice, content pipeline)
- Proof → SLA awareness + consistent tone + escalation logic

**Enterprise**
- Input → business unit brief
- Output → architecture + pricing + onboarding + GTM as reusable assets
- Proof → licensing-ready IP package
